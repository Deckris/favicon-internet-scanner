# Security and responsible use

Report a vulnerability in this scanner through GitHub's private vulnerability reporting
(the repository's *Security* tab, *Report a vulnerability*). Please do not open a public issue for it.

This software sends network traffic to hosts you do not control. Running it against the Internet needs the
approvals your institution requires, an information page, a monitored contact address and an exclusion list.
The program refuses to run without an approval file that matches its config. If you receive unwanted traffic
from a scanner built from this code, contact the operator named in its user agent.
